Design System Showcase

10 systems · pick exactly one

Pick ONE. Never mix two.

Each system supplies palette + type + spacing rhythm so output is cohesive by construction. Full specs and CSS token blocks in references/design-systems.md. The Dark Private-Client system is the default for any brief described as "premium / modern / sophisticated."

Dark Private-Client default

Real estate · finance · wealth management

Display: Fraunces (numbers only)

Body: Inter

Near-black canvas + warm bronze dodges all three AI-slop defaults while reading as private-banking software. Use for any "premium / luxury / exclusive" brief.

Minimal-Tech

Linear · Vercel · dev tools

Display: Geist / Inter Tight

Body: Inter

Tight 4px grid, hairline dividers, generous negative space. Best for SaaS dashboards and developer productivity tools. Add a signature element — plain it reads as generic SaaS.

Warm-Sophisticate

Arc · Raycast · consumer apps

Display: Fraunces / Instrument Serif

Body: Inter

Soft large radii (16–24px), layered shadows, tactile and friendly-but-premium. Best for consumer apps, lifestyle, creative tools, and onboarding flows.

Editorial

Stripe · Notion · fintech docs

Display: General Sans / Söhne

Body: Inter

Strong typographic hierarchy, ruled sections, precise 8px grid. Data-dense but airy. Best for fintech, documentation, and credibility-forward marketing.

Dark-Luxe

Premium product · portfolio · agencies

Display: Playfair Display / Cormorant

Body: Spline Sans

High contrast, muted gold accent, cinematic hero. Best for portfolios, luxury product launches, and agency showcase pages.

Boutique E-Commerce

Luxury storefront · fashion catalogs

Display: Cormorant Garamond (italicised)

Body: Plus Jakarta Sans

Extreme whitespace, full-aspect zoom-on-hover images, floating slide-over drawers. Best for luxury storefronts, designer collections, and jewellery checkouts.

Neo-Brutalist

Indie-hacker · Figma-style utilities

Display: Clash Display / Syne

Body: Space Grotesk

Sharp 2px solid borders, flat solid black shadow offsets, zero gradients, zero rounded pills. Best for indie hacker startups and bold creative dashboards.

Conversational AI Workspace

Chat · custom agents · canvas UIs

Display: Geist Sans / Cabinet Grotesk

Body: Geist / Inter

Centered prompt bars, collapsible sidebars, streaming text blocks, surgical cyan accent. Best for custom LLM workspaces and AI-chat canvases.

Organics & Wellness

Healthcare · mindfulness · Calm-style B2C

Display: Outfit / Cabinet Grotesk

Body: Inter / Plus Jakarta Sans

Large soft radii (20–32px), deep diffused shadows, soothing overlays, generous whitespace. Best for meditation trackers, organic stores, and medical dashboards.

Terminal Hacker & Retro-Tech

CLI · developer command hubs · ASCII

Display: JetBrains Mono / SF Mono

Body: Geist Mono

Strict monospaced rhythm, ASCII borders, CRT glow text, zero border-radius. Best for developer portfolios, CLI log viewers, and server status monitors.
